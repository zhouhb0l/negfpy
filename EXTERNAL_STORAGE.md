# External resource boundary

Large campaign outputs, checkpoints, generated validation evidence, runtime environments and retained workflow sources are managed outside the lightweight software home. The host-private registry records actual locations, scope, preservation and unresolved relationships.
Keep logical dataset/run identifiers and necessary selected evidence with a scientific deliverable; do not upload whole raw campaigns as software metadata. Preserve existing release and publication bindings.
local-paths.example.json is a non-operational template. Actual machine paths and inherited-instruction locators belong only in ignored local-paths.json or private records. Ensure that file is ignored before writing it in a fresh clone.
The physical checkout can use Git info/exclude for host-local configuration. A preserved copy does not by itself prove independent storage, complete external Git closure or an atomic scientific checkpoint.
