# Supplemental workspace guidance

Read PROJECT_NOTES.md and the scientific/validation documents already maintained by this repository before changing scientific code. This supplemental file does not replace those conventions.
Consult the host-private workspace registry and ignored local-paths.json for inherited scientific/operational instructions and preserved source locations. Their applicability survives a layout change; leave original instructions intact.
Preserve staged, unstaged, useful untracked and relevant ignored work. Do not infer equivalence from matching names or HEADs, overwrite distinct copies, prune retained worktree administration or treat foreign Git pointers as native worktrees.
Keep bulk results and environments external, and record selected data/code provenance. Organization alone does not authorize production calculations, remote jobs, process control, experimental science merges or history rewrites.
Use small existing imports/unit checks for layout verification. Review metadata separately from scientific changes before publication; the current session defines authorized commits and synchronization.
