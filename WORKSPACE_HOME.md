# Logical software home

The registered logical home is `NEGF/1. software_negfpy`, identified by the stable entity ID `sw-negfpy`.

A logical home does not prescribe a physical move or a particular host path. Consult the host's private workspace registry to find the maintained checkout and any local compatibility mapping. Do not infer that different hosts use the same branch, working state or filesystem layout.

Surrounding studies, material data, reports, environments and archives are separate components. They do not become part of this software repository merely because a home is registered.

`local-paths.example.json` contains portable placeholders only. It introduces no runtime configuration loader and changes no existing path resolution. Resolve host-specific paths through the established workflow and private registry.
