# Software workspace boundary

Start with README.md and WORKSPACE_HOME.md. This repository contains reusable library source, tests, portable examples and documentation.

Follow the existing project guides for installation, development and release requirements. Keep validated releases and current development work distinct. The home metadata does not replace those requirements or certify the current working tree.

Datasets, generated campaigns, environments and recovery archives are configured separately. Consult EXTERNAL_STORAGE.md and the host's private registry rather than assuming a shared physical layout.
